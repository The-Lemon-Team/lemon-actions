# ☁ Tab Cloud — Умное Облако Табов для Google Chrome

Легковесное персональное расширение для Chrome (Manifest V3) со счетчиком вкладок, историей их жизненного цикла и плавающим облачным интерфейсом с Drag & Drop.

---

## 🚀 Установка за 30 секунд (Режим разработчика)

Для личного использования расширение не требует публикации в Chrome Web Store:

1. Откройте Google Chrome и перейдите по адресу:
   ```text
   chrome://extensions/
   ```
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
3. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
4. Выберите папку:
   ```text
   C:\Users\Ilege\projects\lemon-actions\chrome-tab-cloud
   ```
5. **Готово!** Иконка с облаком появится на панели инструментов браузера (закрепите её булавкой 📌 для постоянного доступа).

---

## ✨ Что умеет расширение:

1. **Живой счетчик на иконке браузера**:
   - Автоматически показывает точное количество открытых вкладок в реальном времени.
2. **Парящий облачный список**:
   - Эстетичный полупрозрачный интерфейс («стекломорфизм» + мягкие градиенты).
   - Список слегка плавно левитирует в воздухе.
3. **Drag & Drop (DnD)**:
   - Перетаскивайте вкладки за иконку `⠿` или саму карточку вверх и вниз.
   - **Синхронизировано с браузером**: изменение порядка в облаке автоматически меняет порядок вкладок на панели Chrome (`chrome.tabs.move`)!
4. **Хронология и конечные точки**:
   - Фиксирует точное время открытия и сколько вкладка уже активна (минуты, часы, дни).
   - Подсвечивает старые «забытые» вкладки.
   - Если внутри вкладки совершались переходы — доступна кнопка раскрытия цепочки шагов.
5. **История закрытых вкладок**:
   - Сохраняет время закрытия и точную продолжительность жизни таба.
   - Кнопка «Восстановить» в 1 клик открывает закрытую вкладку снова.
6. **Быстрый поиск**:
   - Мгновенная фильтрация по названию или домену.
7. **Полноэкранный Dashboard**:
   - Кнопка `⤢` открывает полноразмерный облачный центр управления в отдельной вкладке.
