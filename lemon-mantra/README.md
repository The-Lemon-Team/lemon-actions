# Lemon-Mantra

Персональный трекер динамики состояния и энергии по чакрам (энергетическим центрам) в течение дня.

## Ключевая идея

Обычные трекеры настроения фиксируют одну абстрактную точку раз в день. **Lemon-Mantra** фиксирует **изменения состояния в теле и сознании по ходу дня**:

- **Утро:** голова работает свежо, мысли не теряются → `Голова: 10/10`, `Грудь: 10/10`.
- **Вечер:** накопилась усталость и эмоциональная нагрузка → `Голова: 7/10 (-3)`, `Грудь: 3/10 (-7)` + короткий тег/комментарий, что повлияло.

Главная ценность — видеть **дельту (сдвиг)**, точку перелома в течение дня и то, какие события, люди или практики поднимают или роняют ресурс конкретных центров.

## Столпы продукта

1. **Чек-ин за 5–10 секунд (Delta-first UX)**
   - Подтягивает предыдущие значения; достаточно сдвинуть только те зоны, где изменилось ощущение.
   - Быстрые теги-триггеры (`созвон`, `глубокая работа`, `прогулка`, `конфликт`, `кофе`, `отдых`) + опциональная заметка.
   - Опциональный маркер *качества* ощущения (`ясность`, `поток`, `зажим`, `тяжесть`, `пустота`, `жар`).
2. **Динамика и аналитика**
   - Кривая дня по каждой зоне (утро → день → вечер).
   - Поиск утечек и подзарядок (корреляция тегов с изменением баллов).
   - Индекс баланса/перекоса (например, «высокая голова при пустом теле/груди»).
3. **Аптечка состояния и мантры**
   - Точечные микро-практики на 1–3 минуты при резком падении центра.
   - Повторный замер «До → После» практики для проверки реального эффекта.
   - Личные мантры / фразы-якоря для каждой чакры.
