# Пользовательские сценарии и структура экранов

## Ключевые потоки (User Flows)

### Поток 1: Первый чек-ин дня (Базовая точка)
1. Пользователь открывает приложение.
2. Видит вертикальную ось / мягкий силуэт с активными зонами (по умолчанию 3–7 на выбор).
3. Проставляет стартовые значения (например, `Голова: 10`, `Грудь: 10`).
4. Нажимает «Зафиксировать» — точка дня сохранена.

### Поток 2: Повторный замер в течение дня (Режим «Дельта»)
1. К вечеру пользователь возвращается, чтобы отметить изменения.
2. На экране уже отображаются последние сохранённые баллы (`10` и `10`, подпись «7 ч назад»).
3. Пользователь тянет ползунок `Голова` до `7` (рядом сразу появляется бейдж **`-3`**) и `Грудь` до `3` (бейдж **`-7`**).
4. Отмечает 1–2 тега (`созвон`, `долгая работа`) и при желании добавляет фразу: *«мысли вязнут, в груди пусто»*.
5. Сохраняет — лента дня обновляется, фиксируется вектор изменения.

### Поток 3: Отклик на резкую просадку (Аптечка / Мантра)
1. Если `delta <= -3` или `score <= 4`, приложение не навязчиво, а мягко предлагает карточку поддержки именно для просевшей зоны (например, для `Грудь 3/10` — *«2 минуты дыхания сердцем»* или личная мантра).
2. Если пользователь запускает микро-практику, по окончании таймера предлагается обновить балл этой зоны в 1 тап → сохраняется эффект `+N`.

## Структура экранов MVP

1. **Главный экран «Сейчас» (Check-in + Силуэт):**
   - Интерактивная карта центров с плавным свечением по текущему баллу `0–10`.
   - Быстрые слайдеры/тапы + индикатор дельты от прошлого замера.
   - Полоса тегов-триггеров и компактная заметка.
2. **Экран «День и Лента» (Timeline):**
   - График кривой энергии за день (линии по выбранным центрам).
   - Хронологическая лента сдвигов: `10:00 → 14:30 (-2) → 20:15 (-5)`.
3. **Экран «Паттерны и Практики» (Этап 2–3):**
   - Топ-триггеры, которые чаще всего роняют или восстанавливают ресурс.
   - Редактор личных мантр, настройка активных зон (2–7) и библиотека коротких практик.

## Визуальные и технические ориентиры (экосистема Lemon)

- **Визуальный стиль:** при интеграции с экосистемой можно опереться на палитру из `../../DESIGN.md` — тёплый «бумажный» фон (`#fbf9f5`), мягкие поверхности, тёплый лимонно-золотой акцент (`#f7d02c`) и шрифт `Hanken Grotesk`, дополненные спокойными природными цветами чакр без визуального шума.
- **Сервисные правила (если позже станет веб-сервисом в монорепо):**
  - При работе в браузерных модалках — соблюдать стандарты из `.agents/rules/modal-interaction.md`.
  - При запуске собственного локального сервера — регистрировать порт через Port Shield (`lemon_register_app`).
