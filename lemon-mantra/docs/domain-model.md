# Доменная модель Lemon-Mantra

Модель построена вокруг **событий изменения состояния (CheckIn)**, чтобы естественным образом считать дельты (`10 → 7`, `10 → 3`), строить кривую дня и не заставлять пользователя каждый раз заново заполнять все 7 центров.

## Основные сущности

### 1. `EnergyCenter` (Чакра / Зона внимания)
Справочная сущность (см. `../data/chakras.seed.json`).

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `string` | Ключ (`crown`, `third_eye`, `throat`, `heart`, `solar_plexus`, `sacral`, `root`) |
| `order` | `number` | Позиция сверху вниз (`1..7`) или снизу вверх |
| `bodyLabel` | `string` | Понятное бытовое название (`Голова / Мысли`, `Грудь / Сердце` и т.д.) |
| `sanskritName` | `string` | Традиционное название (`Сахасрара`, `Аджна`, `Анахата`...) |
| `colorHex` | `string` | Мягкий цветовой акцент зоны |
| `enabledByDefault` | `boolean` | Включена ли в упрощённом режиме новичка |
| `personalMantra` | `string?` | Личный текстовый якорь / мантра пользователя |

### 2. `CheckIn` (Момент фиксации изменений)
Один заход пользователя в приложение в конкретный момент времени.

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `string` | UUID записи |
| `timestamp` | `ISO8601` | Точное время замера |
| `readings` | `CenterReading[]` | Изменённые (или подтверждённые) оценки по центрам |
| `triggers` | `string[]` | Теги-события, предшествовавшие сдвигу (`созвон`, `прогулка`, `код`) |
| `note` | `string?` | Короткая свободная заметка о состоянии |
| `practiceSessionId` | `string?` | Ссылка на практику, если чек-ин сделан сразу «После» неё |

### 3. `CenterReading` (Оценка конкретной чакры внутри `CheckIn`)

| Поле | Тип | Описание |
| --- | --- | --- |
| `centerId` | `string` | ID из `EnergyCenter` |
| `score` | `number` | Текущий уровень энергии (`0..10`) |
| `previousScore` | `number?` | Значение на момент прошлого замера (для дельты) |
| `delta` | `number?` | Вычисляемый сдвиг (`score - previousScore`, например `-3`, `-7`, `+2`) |
| `quality` | `string?` | Опциональное качество ощущения (`clarity`, `flow`, `tension`, `heaviness`, `emptiness`, `heat`) |

### 4. `PracticeSession` (Микро-практика / Мантра)
Позволяет замерять эффективность восстановления.

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `string` | UUID сессии |
| `targetCenterId` | `string` | На какую чакру направлена практика |
| `practiceId` | `string` | Идентификатор техники (дыхание, тишина, заземление, личная мантра) |
| `durationSec` | `number` | Длительность |
| `beforeCheckInId` | `string` | Чек-ин до начала (например, `Грудь: 3/10`) |
| `afterCheckInId` | `string?` | Чек-ин после (например, `Грудь: 6/10`, дельта `+3`) |

## Пример JSON-записи дня (вечерний сдвиг)

```json
{
  "id": "chk_2026_11_14_evening",
  "timestamp": "2026-11-14T20:15:00+03:00",
  "readings": [
    {
      "centerId": "third_eye",
      "score": 7,
      "previousScore": 10,
      "delta": -3,
      "quality": "fatigue"
    },
    {
      "centerId": "heart",
      "score": 3,
      "previousScore": 10,
      "delta": -7,
      "quality": "heaviness"
    }
  ],
  "triggers": ["созвон", "перегруз"],
  "note": "К вечеру голова устала, в груди сильный спад после тяжёлого обсуждения"
}
```
