# Задача 02: Promise Pool & Concurrency Limiter

Реализовать функцию `promisePool(factories, concurrency)`, которая контролирует одновременное выполнение асинхронных операций.

### Требования:
1. Запускает не более `concurrency` промисов в каждый момент времени.
2. Как только один промис завершается, воркер немедленно забирает следующую задачу из очереди.
3. Сохраняет строгий исходный порядок результатов в итоговом массиве, независимо от того, в каком порядке задачи завершились фактически.
4. При ошибке в любой задаче пул прерывает работу и выбрасывает ошибку (поведение аналогично `Promise.all`).
5. Корректно обрабатывает пустой массив и случай, когда задач меньше, чем `concurrency`.
