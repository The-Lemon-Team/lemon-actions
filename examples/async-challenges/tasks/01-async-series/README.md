# Задача 01: Async Series & Waterfall

Реализовать функцию `asyncSeries(tasks, initialValue, options)`, которая выполняет массив асинхронных операций строго последовательно.

### Требования:
1. Выполняет функции по очереди: результат выполнения $i$-й функции передается аргументом в $(i+1)$-ю функцию.
2. Поддерживает как синхронные, так и асинхронные (`Promise`) функции.
3. При возникновении ошибки на любом шаге цепочка немедленно прерывается (fail-fast), последующие задачи не запускаются.
4. Поддерживает параметр `options.signal` (`AbortSignal`) для отмены пайплайна между шагами.
5. При пустом массиве задач возвращает `initialValue`.
