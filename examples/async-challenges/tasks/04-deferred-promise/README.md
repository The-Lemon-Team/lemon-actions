# Задача 04: Deferred Promise (Отложенный промис)

Реализовать паттерн `Deferred` через функцию `createDeferred()`, позволяющую внешнему коду вручную управлять исходом промиса и синхронно опрашивать его статус.

### Требования:
1. Возвращает объект с полями `promise`, `resolve`, `reject`.
2. Предоставляет синхронные геттеры `status` (`'pending' | 'resolved' | 'rejected'`) и `isSettled` (`boolean`).
3. Сохраняет финальное значение в `value` или ошибку в `reason`.
4. Гарантирует строгую идемпотентность: после первого вызова `resolve` или `reject` повторные вызовы игнорируются, состояние промиса не мутирует.
